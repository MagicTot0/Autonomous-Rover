Ultrasonic Sensing

HCSR04 
The HC-SR04 provides the rover's initial distance measurement capability.

It uses an ultrasonic pulse to estimate the distance to an object based on the time required for the echo to return.

Current pin assignment:

Pin	    Function	    BOARD
VCC	    Power	        5 V
TRIG	Trigger signal	D7
ECHO	Echo signal	    D6
GND	    Ground	        GND
